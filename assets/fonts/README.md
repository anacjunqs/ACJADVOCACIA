# Fontes usadas apenas para gerar imagens (Open Graph e ícones)

O site usa `next/font` (Newsreader e Source Sans 3). Estes arquivos TTF existem porque o gerador de imagens
(`next/og`) não lê WOFF2. Ambas as fontes são distribuídas sob a SIL Open Font License 1.1
(https://openfontlicense.org), que permite o uso e a redistribuição.

- Newsreader Medium (Production Type)
- Source Sans 3 SemiBold (Adobe)
